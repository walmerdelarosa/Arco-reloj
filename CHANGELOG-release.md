**Installer / Instalador:** `ArcoReloj-…-setup.exe` · **Portable / Portátil:** `ArcoReloj-…-portable.zip`

### What's new
- Progress can be shown as percentage, in each ring's units (18.5/24 h, 25/60 min, 20/60 s…) or both (Settings → Rings)
- Date, time remaining and bar labels have their own color
- After the workday ends, the clock shows how long until the next one starts
- Installing "for all users" now works: the app goes to Program Files and opens for every user
- The executable includes version information and is ready for code signing

### Novedades
- El avance se puede ver en porcentaje, en las unidades de cada anillo (18.5/24 h, 25/60 min, 20/60 s…) o ambos (Ajustes → Anillos)
- La fecha, el tiempo restante y las etiquetas de las barras tienen color propio
- Al terminar la jornada, el reloj indica cuánto falta para la siguiente
- La instalación «para todos los usuarios» ya funciona: la app va a Archivos de programa y abre para cualquier usuario
- El ejecutable incluye información de versión y queda preparado para la firma de código

If you installed 1.3 or earlier "for all users", uninstall it before installing this version. / Si instalaste la 1.3 o anterior «para todos los usuarios», desinstálala antes de instalar esta versión.
